# The Uptrenders — GitHub Pages Website

Static, dependency-free website for The Uptrenders. It can be hosted directly with GitHub Pages.

## Deploy
1. Create a GitHub repository.
2. Upload the contents of this folder, keeping the `assets` folder beside `index.html`.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/root`.
4. Save. GitHub will publish the site.

The site uses no build step, framework, package manager, or external JavaScript dependency.
